**🚗 Tesla Stock Sales Analysis**

This Power BI dashboard is designed to provide an interactive analysis of Tesla vehicle pricing, sales-related information, financing, mileage, accidents, and Driver Assistance System (DAS) features. The dashboard combines business analytics with an interactive 3D view of Tesla models, making it easier to explore vehicle-specific information.


**🎯 Project Objective**

The objective of this project was to build an interactive business intelligence dashboard that combines vehicle sales/pricing analysis with an engaging 3D model-view experience. It demonstrates how Power BI can be used not only for traditional data visualization but also to create an interactive, visually rich dashboard for exploring different Tesla models and their associated analytical metrics.


**📌 Key Performance Indicators (KPIs):**


 - Avg Price – 57.10K: Shows the average selling price of the Tesla vehicles in the dataset.
   
 - Median Odometer – 40K: Represents the median mileage/odometer reading of the vehicles.
   
 - Average EMI – 892.09: Shows the average estimated monthly installment associated with the vehicles.
   
 - % Without Accident – 0.86: Indicates the proportion of vehicles without an accident record.
   
 - % Of Accident – 0.14: Represents the proportion of vehicles with an accident record.

These KPIs provide a quick overview of the dataset before exploring detailed visualizations.


**Additional Details:**


 - State-wise Analysis: Compares total vehicle prices and EMI across different states.
   
 - DAS Analysis: Compares average prices for Full Self-Driving, Autopilot, and Enhanced Autopilot.
   
 - 3D Model View: Interactive Tesla model icons allow users to select different models and view their corresponding 3D vehicle representation.
   
 - Interactive Dashboard: Combines KPIs, charts, model selection, and 3D visualization to provide an engaging overview of Tesla vehicle and pricing data.
